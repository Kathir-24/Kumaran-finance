## 2. Invariant Layout & Underline Guardrails

1. **Zero Artificial Underlines**:
   - Underlines exist **strictly where a blank line was drawn in the official Gazette form**.
   - No trailing underlines exist on signature blocks (e.g., Chairman, Secretary, Subscriber).
   - Form I Annexure items 1–7 (Gazette p.45) and items 8–12 (Gazette p.46) have **zero underlines in blank mode**, matching the clean Gazette scan.
   - Form VIII Articles I through XXII contain no artificial underlines; only Article VI(3) contains the genuine Gazette underline (`from the ________ defaulter in a lump sum`).
2. **Page-Flow 1-to-1 Parity**:
   - Multi-page forms in the Gazette are generated as discrete pages matching the Gazette page breaks (Form I = 4 pages, Form II = 2 pages, Form VIII = 8 pages).
   - Content expands across the full page width ($45\text{ pt}$ to $550\text{ pt}$ / $505\text{ pt}$ span) so that questions and text never bunch on the mid-left.
3. **Data Entry Styling**:
   - **Blank forms** render the clean, authentic statutory template with underline blanks ready for manual completion or official inspection.
   - **Pre-filled forms** render all system data in **bold blue** (`#003399`) while keeping template statutory prose in black.
4. **Page Density Invariant**:
   - Every single generated page satisfies the bottom gap invariant: **$\text{gap} < 25.0\%$** (strictly not equal to 25%).
   - All 38 generated pages passed the automated pixel density audit with gaps between $11.8\%$ and $20.7\%$.
